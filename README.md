# Eagles Tourism — موقع إيجلز للسياحة (الغردقة)

موقع سياحي كامل باللغة العربية مع لوحة تحكم لإدارة الرحلات والصور والحجوزات.
مبني بـ **PHP + MySQL** بدون أي مكتبات خارجية، ويعمل مباشرة على استضافة **Hostinger**.

## المميزات

**الموقع:**
- صفحة رئيسية: واجهة كبيرة، بحث عن الرحلات، الرحلات المميزة، أنواع الرحلات، معرض لمعالم الغردقة، "من نحن"، آراء العملاء.
- صفحة كل الرحلات: فلترة حسب النوع، بحث، وترتيب حسب السعر.
- صفحة تفاصيل الرحلة: معرض صور يفتح بملء الشاشة، المدة والمكان وموعد الاستلام، ما يشمله السعر وما لا يشمله، برنامج الرحلة بالساعة، ونموذج حجز يحسب الإجمالي تلقائياً، بالإضافة لزر الحجز عبر واتساب.
- صفحة معالم الغردقة (معرض صور).
- صفحة تواصل معنا مع نموذج وخريطة.
- زر واتساب ثابت، والتصميم يعمل على الموبايل.

**لوحة التحكم** (`/admin`):
- إضافة وتعديل وحذف الرحلات: الاسم، النوع، المكان، المدة، سعر البالغ والطفل والسعر قبل الخصم، التفاصيل، صورة الغلاف، ومعرض صور (رفع أكثر من صورة مرة واحدة).
- نشر أو إخفاء الرحلة، وتمييزها لتظهر في الصفحة الرئيسية.
- إدارة صور معالم الغردقة.
- استقبال الحجوزات والرسائل وتغيير حالتها (جديد / تم التواصل / مؤكد / ملغي)، مع زر للرد على العميل عبر واتساب.
- الإعدادات: بيانات التواصل، رقم الواتساب، العملة، نصوص الصفحة الرئيسية، صورة الواجهة، آراء العملاء، وتغيير كلمة المرور.

## الرفع على Hostinger (خطوة بخطوة)

1. **أنشئ قاعدة بيانات:** من hPanel اختر Websites ← Manage ← **Databases** ← Management، ثم أنشئ قاعدة بيانات ومستخدماً واحفظ: اسم القاعدة، اسم المستخدم، وكلمة المرور.
2. **ارفع الملفات:** من **File Manager** افتح مجلد `public_html` وارفع كل ملفات المشروع (يمكنك ضغطها في ملف ZIP ورفعه ثم اختيار Extract).
   - تأكد أن ملف `index.php` موجود مباشرة داخل `public_html`.
   - تأكد أن ملفات `.htaccess` اترفعت (هي ملفات مخفية).
3. **شغّل المعالج:** افتح `https://your-domain.com/install.php` واكتب بيانات قاعدة البيانات، واختر اسم مستخدم وكلمة مرور للوحة التحكم، ثم اضغط "تثبيت الموقع".
4. **احذف ملف `install.php`** من File Manager بعد انتهاء التثبيت لزيادة الأمان.
5. **ادخل لوحة التحكم** من `https://your-domain.com/admin` وعدّل:
   - **الإعدادات:** رقم الهاتف، رقم الواتساب (بالصيغة الدولية مثل `201001234567`)، الإيميل، العنوان، وروابط السوشيال.
   - **الرحلات:** عدّل الرحلات التجريبية أو احذفها وأضف رحلاتك بأسعارك وصورك.
   - **معالم الغردقة:** ارفع صوراً حقيقية لأماكن الغردقة.
6. فعّل شهادة **SSL** المجانية من hPanel (Security ← SSL). الموقع يحوّل تلقائياً إلى https.

> **مهم:** الرحلات والمعالم التجريبية تستخدم صوراً من Unsplash عن طريق روابط، وهي صور توضيحية وليست بالضرورة من الغردقة. الأفضل تستبدلها بصورك الحقيقية من لوحة التحكم. وأرقام الإحصائيات وآراء العملاء أمثلة أيضاً، عدّلها من الإعدادات ببياناتك الحقيقية.

### رفع صور كبيرة
الموقع يصغّر أي صورة أعرض من 1920 بكسل تلقائياً. لو ظهرت رسالة "حجم الصور أكبر من المسموح"، ارفع عدداً أقل من الصور في كل مرة، أو زوّد `upload_max_filesize` و`post_max_size` من hPanel ← Advanced ← PHP Configuration.

## هيكل الملفات

```
index.php, trips.php, trip.php, gallery.php, contact.php   صفحات الموقع
install.php                 معالج التثبيت (احذفه بعد التثبيت)
admin/                      لوحة التحكم
includes/                   الإعدادات والدوال وقاعدة البيانات (محمي من الوصول المباشر)
assets/css, assets/js       التصميم والسكريبتات
uploads/                    الصور المرفوعة (تشغيل ملفات PHP ممنوع داخله)
data/                       ملف القفل بعد التثبيت، وملف قاعدة SQLite لو اخترتها
```

## الأمان
كلمات المرور مشفرة (bcrypt)، وكل النماذج محمية بـ CSRF، والاستعلامات تستخدم prepared statements.
يتم التحقق من أن الملفات المرفوعة صور فعلاً، وتشغيل السكريبتات ممنوع في مجلد الرفع.
وفيه حد لعدد محاولات الدخول الخاطئة.

## التشغيل محلياً (للمطورين)
```bash
php -S localhost:8000
# افتح http://localhost:8000/install.php واختر SQLite
```
المتطلبات: PHP 8.1 أو أحدث مع امتدادات PDO (mysql أو sqlite) وGD.
